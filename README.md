## 📋 Descripción del Proyecto
Este es el Trabajo Final desarrollado para la materia **Programación 3**. Consiste en una plataforma de E-Commerce completa dedicada a la preventa y venta de tickets para eventos, desarrollada bajo una arquitectura de capas en **C# y .NET Framework**.

## 🚀 Funcionalidades Principales
- **Gestión de Eventos:** CRUD completo para administradores (creación, edición y baja de tickets).
- **Carrito de Compras:** Sistema de selección de entradas con persistencia de datos.
- **Autenticación:** Sistema de Login y Registro diferenciado para clientes y administradores.
- **Base de Datos:** Diseño relacional robusto para el manejo de transacciones y stock de entradas.

## 🛠️ Stack Tecnológico
- **Lenguaje:** C#
- **Framework:** .NET Framework
- **Base de Datos:** Microsoft SQL Server
- **Frontend:** ASP.NET Web Forms 

## 🏗️ Arquitectura
El proyecto fue estructurado siguiendo buenas prácticas de desarrollo:
1. **Capa de Dominio:** Entidades del negocio.
2. **Capa de Negocio:** Lógica de servicios y validaciones.
3. **Capa de Datos:** Acceso y persistencia mediante ADO.NET.
